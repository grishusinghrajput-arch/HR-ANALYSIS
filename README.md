# 👥 HR Analytics | Employee Analysis

## 📌 Project Overview

An HR Analytics project focused on analyzing employee data to understand workforce distribution, salary trends, employee performance, job satisfaction, and attrition.

The objective is to transform employee data into meaningful insights that help HR management make better workforce decisions.

## 🛠️ Tools & Technologies

* **Excel:** Data inspection and preparation.
* **SQL (MySQL):** Data analysis, aggregations, subqueries, CTEs, and employee ranking.
* **Power BI:** Interactive dashboards, KPIs, and data visualization.

## ❓ Business Questions

* How many employees are working in the organization?
* Which departments have the highest employee count?
* What is the average salary across departments?
* Which departments have the highest performance ratings?
* How many employees received promotions?
* What is the employee attrition rate?
* Which employees have the highest salaries?

## 💡 Key Insights

* Analyzed a dataset containing **3,000 employee records**.
* Identified employee distribution across 7 departments.
* Evaluated salary distribution and departmental salary trends.
* Analyzed employee performance and job satisfaction.
* Identified **395 employees** with attrition status.
* Compared departmental performance ratings.

## 📊 Dashboard Highlights

* Employee Overview
* Department-wise Analysis
* Salary Analysis
* Performance Analysis
* Employee Attrition
* Job Satisfaction

## 🎯 Project Outcome

Developed an HR analytics solution to understand workforce trends, evaluate employee performance, and identify areas that require HR management attention.
